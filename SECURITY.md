# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's **Report a vulnerability** flow instead of opening a public issue. Include the affected version, reproduction steps, impact, and any relevant logs with account names, tokens, and local paths removed.

Do not include third-party binaries, game files, credentials, or personal data in a report. Allow maintainers reasonable time to investigate before public disclosure.

## Supply-chain scope

This repository embeds third-party components. Security changes should preserve upstream provenance, record component versions, and make binary updates reviewable. Reports about an upstream component should also be shared with that component's maintainer when appropriate.

This policy does not authorize access to systems or content you do not own, disruption of services, or bypassing software licenses.
